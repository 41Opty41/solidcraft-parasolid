# Contributing to solidcraft-parasolid

Contributions are welcome under the **clean-room** policy of this repository.

## Clean-Room Rules
- Never copy, decompile, or reference proprietary CAD vendor code or binaries.
- Test fixtures in `solidcraft-parasolid/tests/` must be purely synthetic models generated by open scripts (`scripts/gen_fixtures.py`) — never commit commercial or customer CAD files.
- Keep `xtopen-core` and `solidcraft-parasolid-wasm` free of WASI imports (`wasm32-unknown-unknown`).

## Local Setup & Checks

```powershell
# Run Rust unit and integration tests
cargo test --workspace

# Build native CLI + WebAssembly Component + release zip
.\scripts\build-plugin.ps1

# Validate and run end-to-end tests with SolidCraft CLI (>= 0.50.0)
solidcraft-cli plugin check .\solidcraft-parasolid
solidcraft-cli plugin test .\solidcraft-parasolid --require-cases
```
